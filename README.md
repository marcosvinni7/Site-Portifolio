# Nacao 1895

Loja React de camisas do Flamengo, com catalogo atual, camisas retro, busca, filtros, animacoes e carrinho.

## Executar

Requer Node.js 18 ou superior.

```bash
npm install
npm run dev
```

Depois, abra o endereco exibido pelo Vite.

## Estrutura

- `index.html`: entrada do Vite
- `src/App.jsx`: componentes e estado da loja
- `src/styles.css`: estilos da aplicacao
- `src/main.jsx`: inicializacao do React
- `public/imagens/`: imagens locais dos produtos
- `vite.config.js`: configuracao do Vite
